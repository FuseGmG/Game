# Game

**Game** ist ein modernes, futuristisches Browser-Game, bei dem es auf deine Reaktionsgeschwindigkeit ankommt. Das Ziel ist es, innerhalb von 30 Sekunden so viele zufällig erscheinende Ziele wie möglich anzuklicken.

## Features

- **Score-System:** Erreiche die höchstmögliche Punktzahl durch schnelles Klicken.
- **Timer:** Ein 30-sekündiger Countdown setzt den Zeitdruck.
- **Zufällige Ziele:** Objekte erscheinen an unvorhersehbaren Positionen auf dem Spielfeld.
- **Responsive Design:** Optimiert für Desktop, Laptop, Tablet und Smartphone.
- **Touch-Unterstützung:** Volle Interaktivität auf mobilen Geräten.
- **Game-Over-System:** Anzeige des finalen Scores und schnelle Neustart-Option.
- **Modernes Design:** Dunkler Modus mit Neon-Effekten und flüssigen Animationen.

## Installation

Da es sich um ein reines Frontend-Projekt handelt, ist keine Installation erforderlich.

1. Erstelle ein neues Repository auf GitHub.
2. Lade die folgenden Dateien in das Root-Verzeichnis hoch:
   - `index.html`
   - `style.css`
   - `script.js`
   - `README.md`
3. Speichere die Änderungen (Commit).

## GitHub Pages

Um das Spiel online zu stellen, folge diesen Schritten:

1. Gehe in deinem GitHub-Repository auf den Tab **Settings**.
2. Klicke in der linken Seitenleiste auf **Pages**.
3. Wähle unter "Build and deployment" $\rightarrow$ "Branch" den Branch `main` (oder `master`) aus und klicke auf **Save**.
4. Warte einige Minuten. GitHub wird dir oben auf der Seite einen Link anzeigen (z.B. `https://dein-nutzername.github.io/Game/`).
5. Klicke auf den Link und spiele das Game direkt im Browser!
